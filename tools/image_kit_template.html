블루 아워 이미지 키트

받은 이미지(배경·캐릭터)는 미리 완료로 표시해 두었습니다. 남은 것은 이벤트 CG입니다. 게임에 들어갈 그림을 GPT 이미지 생성으로 뽑기 위한 주문서입니다. 시작 메시지로 그림체를 한 번 정해 두고, 배치 메시지를 하나씩 붙여넣으면 여러 장이 순서대로 나옵니다.

1

새 대화에 시작 메시지 붙여넣기

그림체와 작품 설정, 진행 규칙을 GPT에게 먼저 알려 줍니다. 그림체 참고 이미지가 있으면 이 메시지와 함께 첨부하세요. 캐릭터나 의상은 가져오지 말라고 메시지에 적어 두었습니다.


    

    

      
2

      
배치 메시지를 하나씩 붙여넣기

      
한 배치는 2~10장입니다. 다 나오면 다음 배치를 붙여넣으세요. 권장 순서는 아래 목록 순서입니다(히로인 → 조연 → 핵심 배경 → 나머지 배경 → 이벤트 CG).

      
    
        
  • 캐릭터는 1번 기본 표정을 먼저 만들고 같은 그림에서 표정만 바꿉니다. 기본 표정이 마음에 들 때까지 다시 뽑은 뒤 진행하세요.
    • 
        
  • 중간에 멈추면 계속 이라고 보내면 이어서 만듭니다.
    • 
        
  • 대화가 길어져 그림체가 흐려지면, 새 대화에서 시작 메시지부터 다시 붙여넣으세요.
    • 
      

    

    

      
3

      
파일명대로 저장해서 가져오기

      
각 이미지 위에 적힌 파일명으로 저장한 뒤 저에게 보내 주시면 게임에 넣겠습니다. 직접 넣으려면 항목마다 적힌 폴더에 두면 됩니다. 확장자는 png·jpg·webp 모두 됩니다.

      

        
      

      
ZIP 요청은 GPT 환경에 따라 동작하지 않을 수 있습니다. 그럴 때는 이미지를 하나씩 내려받으세요. 완료한 항목은 체크해 두면 이 브라우저에 기억됩니다.
